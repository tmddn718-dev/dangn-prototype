# AS-IS — 실제 당근 앱 대형 가구 거래 화면

대형 가구를 검색하고 상품 상세를 확인하는 실제 당근 앱 화면 캡처예요. 개선안(TO-BE)과 비교할 때 AS-IS 이미지로 사용해요.

개인정보 보호를 위해 판매자 닉네임, 거래 희망 장소 상세 주소와 지도, 캡처한 사람의 닉네임·동네는 가렸어요.

| 파일 | 화면 | 가린 정보 | 비교할 TO-BE |
|---|---|---|---|
| [01-search-results.png](01-search-results.png) | '대형가구' 검색 결과 | 없음 | S1 · 홈 |
| [02-detail-top.png](02-detail-top.png) | 상품 상세 · 상단 (사진, 판매자, 가격) | 판매자 닉네임 | B1 · 상세 · 모두 입력 |
| [03-detail-description.png](03-detail-description.png) | 상품 상세 · 본문 (크기 정보가 본문 자유 텍스트에 있어요) | 거래 희망 장소 주소, 지도 | B1, B2 · 거래 정보 카드 |
| [04-detail-location.png](04-detail-location.png) | 상품 상세 · 거래 장소, 용달비 안내 | 주소, 지도, 동네 이름, 닉네임 | B2 · 확인되지 않은 정보 |
| [05-detail-related.png](05-detail-related.png) | 상품 상세 · 비슷한 물품 | 없음 | — |
