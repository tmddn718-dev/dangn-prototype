# TO-BE 전체 스크롤 화면

개선안 29개 화면(판매자·구매자)을 스크롤 끝까지 한 장으로 담은 PNG예요. iOS 상태 바, 노치, 홈 인디케이터를 포함하고, 폭 390pt를 2배(780px)로 저장했어요.

- 스크롤이 없는 화면은 390×844(iPhone 13·14), 긴 화면은 폭 390에 내용 길이만큼이에요(최대 390×1809).
- 앱 화면은 상태 바(47)와 홈 인디케이터(34) 사이의 안전 영역(763)에 들어가요.
- 프로토타입의 '전체 스크롤' 보기(`#full`)와 같은 내용이에요.
